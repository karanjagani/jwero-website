# Blueprint v1 — superseded

`JWERO_WEBSITE_BLUEPRINT.md` in this folder is the **first** Jwero website blueprint, written
2026-07-19 in the `pim` repo before this site had its own repository. It is kept here for
historical reference only — **`../sections/` (Blueprint v2) supersedes it** and is the current
source of truth for IA, positioning and copy strategy.

What v1 got right and v2 changed:

- **Category label** — v1 recommended "Jewellery Growth Engine" (ceding the "Jewelry Operating
  System" phrase to SIONIQ). The founder overrode this in v2: Jwero claims **"The AI Operating
  System for Jewellery Business"** outright, differentiated by the "AI" qualifier and India-native
  depth rather than avoiding the label fight. See `../sections/01-part1.md` §1.1.5.
- **Segment framing** — v1's flagship line ("Chains have systems. Now you have one.") implicitly
  cast chains as the enemy. v2 corrected this to segment-neutral: the enemy is "disconnected
  software that forgets customers," never a business's own peers or competitors by size.
- **Design system** — v1 shipped an invented luxury gold/serif "paper" theme. v2 uses the real
  Jwero product design system (Inter, royal blue `#0013b7`, the actual logo mark).
